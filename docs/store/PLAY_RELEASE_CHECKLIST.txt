MDesk Android Remote 1.6.5 (2006) - Release preparation
Prepared: 2026-10-03
Status: source changes prepared; NOT built, submitted or released.

Source changes
- Settings > Account > Request account deletion is available when logged out.
- The user explicitly opens a deletion request email draft. The app does not
  send an email, automatically log out, or delete data itself.
- Default contact: metadtlab@gmail.com, for MetaDataLab service accounts.
  Independently hosted/customer-managed accounts should contact their server
  administrator. No credentials/tokens are added to the draft.
- If there is no mail handler, the address can be selected or copied.
- Mobile Privacy Statement now opens the published privacy-policy.html.
- Flutter build number is 2006. Code 2005 has already been uploaded and cannot
  be reused. The marketing version remains 1.6.5.

Source-only verification
- 19 selected tests passed: account_deletion_dialog_test.dart,
  account_request_scope_test.dart and login_session_status_test.dart.
- Dialog/translation/test analysis passed. Settings page analysis has the
  existing unused shareScreenTiles warning, unrelated to this change.
- login_response_test.dart could not load in the clean worktree without the
  ignored generated_bridge.dart. It is not included in the passing-test count.
- No Android/Windows build or final-device validation was run on this Mac.

Build on the user's Android build machine
1. Use the source revision containing these changes; preserve local keystore
   and signing configuration. Do not add either to Git or source downloads.
2. Run the existing build_android_remote_release_aab.bat from the repo root.
   It builds release Remote flavor (kr.co.mdesk.remote), not Android Host.
3. Output: flutter\build\app\outputs\bundle\remoteRelease\app-remote-release.aab
   Suggested delivery name: MDesk-Remote-v1.6.5-code2006.aab
4. Confirm the exact final bundle versionCode 2006 / versionName 1.6.5, upload
   certificate continuity, target SDK, native 16 KB compatibility and release
   signing. Test the final installed artifact, not just its filename.
5. On the final Android app, test Settings > Account > Request account deletion
   both logged in and logged out, including no mail app and clipboard fallback.
   Confirm original login and remote control still work.
